# AI agent usage

Read in order: `SKILL.md` → `product.md` → `design.md` → relevant docs → `tokens/manifest.json`/token view → existing Figma or implementation evidence.

A token exists only if it appears in the export. A component is approved only with registry/source evidence. A plausible value is not evidence. Label absent decisions **proposed**.

Recommended prompt:

> Use the Paryatech design-system skill. Identify workflow and role, reuse only existing tokens and approved patterns, and list gaps as proposals. Do not invent raw values or silently add patterns. Report states, responsive behavior, and accessibility.

Review by asking what source proves each major decision, whether semantic roles were used, whether a near-duplicate appeared, whether operational/permission states exist, and whether customer data is safely separated.

# Accessibility

- Meet WCAG 2.2 AA contrast.
- Use exported focus roles and preserve visible focus.
- Support logical keyboard order without traps.
- Prefer semantic HTML/accessibility names before ARIA.
- Use `Sizing.Accessibility.*` for targets.
- Pair status color with non-color cues.
- Support 200% zoom and reduced motion.
- Put actionable errors near fields.
- Make loading programmatically meaningful without noisy skeleton announcements.

Components must define keyboard/focus behavior, labels, errors, disabled/read-only meaning, and motion considerations.

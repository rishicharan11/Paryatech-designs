# Typography

Use `Typography.*`, not assembled `Core.Font *` values. Onest is for headings/titles; Public Sans for UI, body, labels, tables, dates, IDs, and money. Use tabular numerals for aligned financial/date/table data. Preserve semantic hierarchy and solve layout through priority/wrapping/density before shrinking text.

JetBrains Mono exists in exports but is not a default product face; use only for a documented technical-data pattern.
